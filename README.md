# Deniable

Synthetic test data for difficult inputs.

Deniable provides pre-generated synthetic documents with deliberate edge cases for:

- AI system evaluation
- RAG pipeline testing
- parser and document workflow QA
- chatbot and classification testing
- model training and fine-tuning
- email and EML parser testing
- CRM, BI, and automation workflows

Choose a fixed dataset pack for a complete ZIP collection, or use prepaid API credits to retrieve authenticated cases as structured JSON.
